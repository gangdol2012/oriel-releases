# Oriel

Windows 11 on your Mac.

**[Download the latest version](https://github.com/gangdol2012/oriel-releases/releases/latest)**

## Requirements

- A Mac with Apple silicon (M1 or later)
- macOS 26 or later
- Windows 11 is downloaded from Microsoft during setup; activating it needs your own Windows license

## Install

Open `Oriel-<version>.dmg` and drag Oriel to Applications.

## Files in each release

- `Oriel-<version>.dmg`: the app, signed and notarized by Apple
- `Oriel-<version>-source.tar.gz`: source code of the open-source parts under the GPL, LGPL and similar licenses, as built for that version (QEMU with Oriel's changes, Samba and more; see Help > Open-Source Licenses in Oriel)
- `SHA256SUMS`: checksums of both
